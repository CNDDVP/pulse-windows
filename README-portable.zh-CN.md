# Pulse for Windows 便携版使用说明 (Portable Edition)

感谢使用 Pulse for Windows 便携版！

便携版专为免安装、U 盘随身携带或隔离多套配置环境设计。

---

## 快速使用

1. **直接启动**：双击运行目录下的 `Pulse.exe`。
2. **数据存储**：
   - 首次运行后，程序会自动在同级目录生成 `data/` 文件夹。
   - 所有设置（`settings.json`）、Token 账本（`ledger.db`）、离线缓存与 WebView2 运行数据均存放在 `data/` 内部。
   - 若要完全重置便携版，只需退出程序后删除 `data/` 目录即可。
3. **保持便携模式**：请保留程序同目录下的 `portable.flag` 标记文件，请勿删除。

---

## 凭据与安全说明

1. **凭据去向**：为保障安全，您的 API Key 与访问 Token **绝不以明文保存在文件夹中**，而是通过 Windows 原生凭据管理器（Credential Manager，经系统 DPAPI 高强度加密）保存。
2. **移动目录**：在同一台电脑上，您可以自由将本文件夹移动或重命名到任意盘符与路径，Pulse 会通过内置的 Profile 身份自动匹配并保留您的凭据。
3. **换机与跨用户隔离**：将本文件夹拷贝至其他电脑或切换 Windows 系统登录用户时，由于新系统凭据管理器中未存入该身份的凭据，Pulse 会安全显示“需要配置”，绝不会泄露您原电脑上的凭据。
4. **彻底清理**：若您不再使用某台电脑上的 Pulse，可在“设置” -> “关于”页面中点击 **“清理本机关联凭据”**，即可一键从系统凭据管理器中注销当前便携版的全部密钥。

---

## 注意事项

- **系统要求**：Windows 10 / 11 (x64)，需安装 Microsoft Edge WebView2 运行时（Windows 11 系统已默认自带）。
- **开机自启**：为避免文件夹移动后在系统注册表中残留死链，便携模式下已自动禁用开机自启功能。若需要长期开机自动运行，推荐使用官方安装版或手动为 `Pulse.exe` 创建快捷方式放入“启动”文件夹。
