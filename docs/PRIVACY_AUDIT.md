# Pulse for Windows: 隐私审查与开源清洗报告 (Privacy Audit Report)

本报告详细记录了 Pulse for Windows 在开源与构建发布前执行的系统性隐私与敏感数据清洗结果。

## 零遥测与隐私承诺 (Zero-Telemetry Policy)

1. **无任何埋点与分析**：Pulse for Windows 不包含任何分析统计代码（如 Google Analytics、Sentry、PostHog 等），绝不向任何第三方或开发者服务器回传任何使用数据或遥测信息。
2. **纯本地网络通信**：除用户在设置中主动配置的 AI 服务商 API（或本地 Ollama/Antigravity 服务）及 Token Spend 本地日志解析外，应用不进行任何隐式后台通信。
3. **原生凭据安全存储**：API Key 与访问令牌绝不保存于 `settings.json` 等明文配置文件中，全量交由 Windows 原生凭据管理器（Credential Manager，经 DPAPI 加密保护）。

## 隐私清洗范围与核查清单 (S01 ~ S08)

| 编号 | 审查范围 | 审计规范与实施动作 | 审查结论 |
|---|---|---|---|
| **S01** | API Key、Token、私钥与证书 | 对全量源码、测试用例及配置文件执行深度正则模式匹配扫描，杜绝真实密钥硬编码。单测仅使用公开测试向量或合成数据。 | ✅ **通过**（零敏感凭据） |
| **S02** | 开发者姓名、邮箱、路径与个人额度 | 文档、矩阵及配置中的私人绝对路径已转换为标准相对路径；移除实测个人使用量指标，仅保留技术支持状态。 | ✅ **通过**（全面脱敏） |
| **S03** | 运行数据、缓存与备份文件 | `settings.json`、`usage-cache.json`、`alerts.json`、SQLite 数据库及历史 `.bak` 备份文件已纳入 `.gitignore`，严禁纳入版本库。 | ✅ **通过**（排除运行产物） |
| **S04** | 公开文档、截图与矩阵 | 审查 `README.md`、`docs/` 下全部说明文档；所有截图与演示文案均采用合成示例。 | ✅ **通过**（合规无泄露） |
| **S05** | Git 元数据与公开提交历史 | 开源仓库重建全新单条公开 Commit；作者邮箱统一配置为 GitHub 保密邮箱 (`@users.noreply.github.com`)，隔离本地历史。 | ✅ **通过**（历史纯净） |
| **S06** | 锁文件与依赖源合规性 | 检查 `package-lock.json` 与 `Cargo.lock`，确认全部依赖来源于 npmjs 官方与 crates.io 公开注册表，无企业私有源配置。 | ✅ **通过**（公开可复现） |
| **S07** | 编译二进制与压缩包残留 | 发布构建剥离 PDB 调试符号，剔除开发环境变量；便携包在隔离 staging 目录中按白名单组装，不携带旧数据。 | ✅ **通过**（构建安全） |
| **S08** | 持续防护机制 | 配置 GitHub Actions CI 流水线，在提交与 PR 阶段自动执行关键字与敏感模式扫描，防范未来代码意外引入隐私数据。 | ✅ **通过**（自动化防护） |

## 凭据存储机制说明

- **安装版**：配置文件存储于 `%APPDATA%\pulse-windows`，凭据写入 Windows 凭据管理器，标识为 `PulseWindows/<profile_id>/<account_id>`。
- **便携版**：配置存储于解压目录下的 `data/` 目录；凭据同样经 Windows 凭据管理器安全托管，换机或跨用户使用时安全隔离，显示“需要配置”。
