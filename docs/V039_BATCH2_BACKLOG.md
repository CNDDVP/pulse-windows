## 设置与凭据事务（优先）

- **A03 设置保存非事务**：`commands.rs update_settings` 读快照释放锁、异步写盘后覆盖内存；
  代际合并只保护位置字段。快速连续修改/凭据操作交错时旧快照可能覆盖新修改。
  验收：串行事务或字段补丁；内存/磁盘/前端三方一致；写盘失败可恢复。
- **A06 凭据变更不广播清空读数**：保存/删除凭据后只发 `settings-updated`，悬浮栏可能
  保留旧额度。验收：凭据变化即清对应读数并广播 `usages-updated`。
- **A18 Profile 损坏静默换身份**：`config.rs get_profile` 解析失败直接新建 ID 并忽略
  写盘失败。验收：保留损坏文件、明确报错；成功持久化后才启用新身份。
- **A25 重新生成身份后状态未同步**：只改身份文件，不清读数/不失效在途请求。
  验收：切换事务化，旧身份结果不得在切换后提交。
- **A26 普通设置自动保存携带账号草稿**：提交整个 settings。验收：普通设置只提交自身字段。
